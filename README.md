# Система LMS (Django + Docker)

Это Система Управления Обучением (LMS), созданная на Django. Проект полностью контейнеризирован с использованием Docker и Docker Compose для обеспечения согласованной среды разработки и эксплуатации.

## 🚀 CI/CD и Автоматическое развертывание

Этот проект настроен на автоматическое тестирование и развертывание с помощью **GitHub Actions**.

- **Continuous Integration (CI):** При каждом `push` в ветку `main` запускается пайплайн, который автоматически собирает Docker-образы и прогоняет тесты Django. Это гарантирует, что новый код не ломает существующую функциональность.
- **Continuous Deployment (CD):** Если тесты успешно пройдены, пайплайн автоматически подключается к удаленному серверу, скачивает последнюю версию кода, пересобирает образы, применяет миграции и перезапускает сервисы. 

Вам **не нужно** выполнять ручной деплой на сервер. Весь процесс полностью автоматизирован.

## ⚙️ Единоразовая настройка сервера

Для работы автоматического развертывания необходимо один раз подготовить удаленный сервер.

1.  **Подключитесь к серверу по SSH.**
2.  **Установите `git`, `docker` и `docker-compose`.**
3.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ваш-логин/ваш-репозиторий.git /путь/к/папке/проекта
    ```
4.  **Создайте и настройте `.env` файл:**
    - Перейдите в папку проекта: `cd /путь/к/папке/проекта`
    - Создайте файл `.env`: `cp .env.example .env`
    - Откройте его (`nano .env`) и впишите **реальные, боевые значения** для всех переменных (`SECRET_KEY`, `STRIPE_API_KEY` и т.д.).

После этого GitHub Actions будет делать всю остальную работу по обновлению.

## 💻 Локальная разработка

Следуйте этим шагам для настройки и локального запуска проекта на вашем компьютере.

### 1. Установите зависимости

Убедитесь, что на вашей системе установлены [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/).

### 2. Настройка переменных окружения

1.  **Создайте файл `.env` из шаблона:**
    ```bash
    cp .env.example .env
    ```

2.  **Отредактируйте файл `.env`** и впишите ваши значения. Для локальной разработки достаточно сгенерировать `SECRET_KEY`. Остальные ключи можно оставить пустыми, если вы не работаете с функционалом оплаты или отправки почты.

### 3. Сборка и запуск проекта

Используйте следующую команду, чтобы собрать Docker-образы и запустить все сервисы в фоновом режиме:

```bash
docker-compose up -d --build
```

Приложение будет доступно по адресу [http://localhost:8000](http://localhost:8000).

### 4. Применение миграций и создание суперпользователя

```bash
# Применить миграции
docker-compose exec web python manage.py migrate

# Создать суперпользователя (админа)
docker-compose exec web python manage.py createsuperuser
```

## 🛠️ Полезные команды

*   **Запустить все сервисы (в фоновом режиме):**
    ```bash
    docker-compose up -d
    ```

*   **Остановить все сервисы:**
    ```bash
    docker-compose down
    ```

*   **Посмотреть логи всех сервисов:**
    ```bash
    docker-compose logs -f
    ```

*   **Посмотреть логи конкретного сервиса (например, `web`):**
    ```bash
    docker-compose logs -f web
    ```

*   **Выполнить любую management-команду Django:**
    ```bash
    docker-compose exec web python manage.py <ваша_команда>
    ```

## 📦 Сервисы

Файл `docker-compose.yml` определяет следующие сервисы:
*   `web`: Приложение Django.
*   `db`: База данных PostgreSQL.
*   `redis`: Сервер Redis, используется как брокер сообщений Celery.
*   `worker`: Воркер Celery для фоновых задач.
*   `beat`: Планировщик Celery beat для периодических задач.
